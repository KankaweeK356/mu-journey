# วิธีคำนวณและผล Network Analysis (V1)

สถานะ: ตัวเลขคำนวณซ้ำได้ ส่วน **การตีความเป็นร่าง (DRAFT) รอเจ้าของงาน (ส้มส้ม) ยืนยัน**
การวิเคราะห์นี้อ่านอย่างเดียว ไม่เปลี่ยนกราฟ โมเดล PageRank อันดับ Top 5 หรือการจับคู่ทริป

## 1. คำสั่งคำนวณซ้ำ

```
python scripts/network_analysis.py --check     # คำนวณใหม่แล้วเทียบกับไฟล์ที่เก็บไว้
python scripts/network_analysis.py             # เขียนไฟล์ผลใหม่ (ใช้เวลาราว 1–2 นาที)
```

ใช้ `networkx==3.7` ตาม `requirements.txt` เปลี่ยนเวอร์ชันแล้วผลของ Louvain อาจต่างได้
ผลไม่ขึ้นกับ `PYTHONHASHSEED` เพราะสคริปต์เรียง ID และแทนด้วยเลขก่อนคำนวณ

| ไฟล์ผล | เนื้อหา |
|---|---|
| `model/results/network_analysis_v1.json` | ผลทั้งหมด รวมสมาชิกทุก Community และ Degree ทุกโหนด |
| `model/results/network_analysis/communities.csv` | สรุปราย Community |
| `model/results/network_analysis/community_members.csv` | สมาชิกและความคงที่รายโหนด |
| `model/results/network_analysis/null_model_samples.csv` | กราฟสุ่ม 1,000 ชุด หนึ่งแถวต่อชุด |
| `model/results/network_analysis/degree_by_type.csv` | Degree แยกตามชนิดความสัมพันธ์ |
| `public/data/network_analysis.json` | ฉบับย่อที่หน้า Network Explorer ใช้ |

## 3. เกณฑ์ที่กำหนดก่อนรัน

เกณฑ์อยู่ในค่าคงที่ต้นสคริปต์ และอิงขั้นตอนตรวจ 4 ข้อของรายวิชา (MADT7202 บทที่ 9)

| ข้อตรวจ | วิธี | เกณฑ์ |
|---|---|---|
| 1 คะแนน | Modularity ของกลุ่มที่แสดง และ Louvain ดีที่สุดจาก 10 รอบ | รายงานค่า |
| 2 เทียบกราฟสุ่ม | กราฟสุ่ม 1,000 ชุด ใช้วิธีคิดเดียวกันกับกราฟจริง | ผ่านเมื่อกราฟสุ่มที่ได้ค่าไม่น้อยกว่ากราฟจริงมีไม่เกิน 5% **ทั้ง** Greedy และ Louvain |
| 3 ความคงที่ | Louvain 100 รอบ (Seed 0–99) วัด co-association | โหนดคงที่เมื่อค่า ≥ 0.80 |
| 4 ขนาดกลุ่ม | ปรับ resolution 0.5 / 1.0 / 1.5 / 2.0 อย่างละ 50 รอบ | รายงานผล |
| การตั้งชื่อ | ผ่านข้อ 2, มีโหนด Wish ในกลุ่ม, สมาชิก**ทุกโหนด**คงที่ | ไม่ครบ → ใช้หมายเลข Community |

เกณฑ์ 0.80 และ 5% เป็นข้อตกลงที่ใช้ตัดสิน ไม่ใช่ความแม่นยำของโมเดล

หมายเหตุเรื่องวิธี: Greedy Modularity ให้ผลเดิมทุกครั้ง จึงทดสอบ Seed ไม่ได้ ข้อ 3 จึงใช้ Louvain
แล้วถามว่าสมาชิกของกลุ่ม Greedy ยังอยู่ด้วยกันบ่อยเพียงใด

ค่า co-association ของโหนด v ในกลุ่ม C = ค่าเฉลี่ยของ (สัดส่วนรอบที่ v กับ u อยู่กลุ่มเดียวกัน) สำหรับ u ทุกตัวใน C ที่ไม่ใช่ v

## 4. กราฟสุ่ม (Null model)

- สลับปลายเส้น **ภายในความสัมพันธ์ชนิดเดียวกัน**: เลือกสองเส้น (a–x), (b–y) แล้วเปลี่ยนเป็น (a–y), (b–x) ถ้าไม่เกิดเส้นซ้ำ
- ทุกโหนดมีจำนวนเส้นในความสัมพันธ์แต่ละชนิดเท่ากราฟจริง จึงรักษาโครงสร้าง Wish–Deity–Place ไม่มีเส้น Wish–Place หรือเส้นชนิดใหม่
- สลับสำเร็จ 10 ครั้งต่อเส้น (1,140 ครั้งต่อชุด) ครบทุกชุด
- Seed ของชุดที่ i = 7202 × 100000 + i
- เส้นที่ยังเหมือนกราฟจริงเฉลี่ยราว 24% ซึ่งส่วนหนึ่งเป็นเพราะโหนดจำนวนมากมีเส้นน้อย (ทางเลือกในการสลับจำกัด)
- p แบบหนึ่งด้าน = (จำนวนชุดที่ ≥ ค่าจริง + 1) ÷ (1,000 + 1)

## 8. ข้อจำกัด

1. กราฟเล็กและเบาบาง (114 เส้น) การทดสอบมีกำลังจำกัด การไม่ผ่านเกณฑ์ไม่ได้พิสูจน์ว่าไม่มีกลุ่ม
2. ทุกเส้น Wish–Deity เป็นความเชื่อที่ยังไม่ยืนยัน เส้น Deity–Place ส่วนใหญ่ยังรอตรวจ (SOURCE 20, CANDIDATE 46)
3. Modularity ใช้กับกราฟรวมทุกชนิดโหนด ไม่ได้ใช้ Modularity เฉพาะกราฟสองฝั่ง กราฟสุ่มช่วยคุมเรื่องชนิดเส้นแล้ว แต่ค่าตัวเลขเทียบข้ามกราฟต่างรูปแบบไม่ได้
4. Greedy Modularity เป็นวิธีเดิมของระบบ รายวิชาแนะนำ Leiden ซึ่งไม่ได้ติดตั้งเพิ่มในรอบนี้
5. ข้อมูลเป็นภาพ ณ วันที่ของ Snapshot ไม่มีมิติเวลา
