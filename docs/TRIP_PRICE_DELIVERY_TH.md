## เพิ่มภายหลัง: Journey การจองแบบสาธิต (ทริปและฝากมู)

คำขอจากเพื่อนผู้ให้ความเห็น: ให้เห็นเส้นทาง จอง → ใช้บริการ → ความคิดเห็น

| ขั้น | ทริป | ฝากมู |
|---|---|---|
| ① จอง | "จองทริป" ที่ขั้น 06 หรือ 07 → เลือกวันใน pop-up → "ยืนยันการจอง" | "จอง" ที่บริการ → กรอกชื่อสมมติ/คำขอ → "ยืนยันการจอง" |
| ② สถานะ | ขั้น 07 ขึ้น "จองสำเร็จ" พร้อมวัน เวลา จุดนัดพบ ราคา ปุ่ม "ใช้บริการ" และ "ยกเลิกการจอง" · แผนเดินทางพับไว้ | การ์ดบริการเปลี่ยนเป็นสถานะจอง พร้อมปุ่มชุดเดียวกัน |
| ③ ใช้บริการ | สถานะเป็น "ใช้บริการแล้ว" เปิดแบบฟอร์มความคิดเห็นเดิม ระบุว่าประเมินระบบสาธิต ไม่ใช่บริการจริง ไม่เลือกคำตอบแทนผู้ใช้ | เหมือนกัน |
| ④ หลังส่ง | "กลับไปหน้าบริการ" · ถ้ามีการจองอีกรายการที่ยังไม่ได้ใช้ มีปุ่มพาไปรายการนั้น · "มูเรื่องอื่นต่อ" และ "กลับหน้าแรก" ยังมี | เหมือนกัน |

- จองทริปและฝากมูพร้อมกันได้ ทริปจองได้ 1 รายการ ฝากมูจองได้หลายบริการ
- ปิดแบบฟอร์มหรือบันทึกไม่สำเร็จ กด "ให้ความคิดเห็น" ที่การ์ดเปิดใหม่ได้ ขึ้น "ส่งความคิดเห็นแล้ว" เฉพาะเมื่อบันทึกสำเร็จ
- ไม่มีการส่งคำขอจอง ไม่เก็บข้อมูล ไม่ออกเลขที่การจอง ส่งเฉพาะความคิดเห็นเมื่อผู้ใช้ยินยอม ด้วยฟิลด์เดิม
- สถานะอยู่ในหน่วยความจำของหน้าเว็บ หายเมื่อโหลดหน้าใหม่หรือเปลี่ยนข้อมูลโปรไฟล์
- ทุกจุดจองมีข้อความว่าเป็นระบบสาธิต ปุ่มไม่มีคำว่า "(จำลอง)" ต่อท้ายแล้ว
- หลังจองทริป ปุ่ม "แสดงความสนใจทริป" และ "ดูเหตุผลที่แนะนำทริปนี้" ถูกซ่อน (ก่อนจองยังมี)
- ขั้น 07 ไม่มีปุ่มความคิดเห็นที่มุมล่างแล้ว กล่องไปมูเองใช้ปุ่ม "ให้ความคิดเห็น" · ถ้าฝากมูไม่มีบริการให้เลือก ต้องส่งความคิดเห็นจากกล่องไปมูเอง
- วันที่ที่เลือกเปลี่ยนจากสีชมพูมี ✕ (ผิดความหมาย) เป็นสีม่วงมี ✓
- **ขอบเขต:** Requirement เดิมห้ามเพิ่มระบบจองจริง ส่วนนี้เป็นการจำลองหน้าจอ **ต้องให้ผู้ตรวจรับเห็นชอบ**
