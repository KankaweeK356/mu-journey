# แหล่งข้อมูล (Data Sources) และที่มาของไฟล์ใน repo นี้

ข้อมูลทุกไฟล์ที่ระบบใช้ **อยู่ใน repo นี้** รันซ้ำได้โดยไม่ต้องเข้า Google Drive รหัส `sha256` ย่อ (12 ตัวแรก) ไว้ตรวจว่าไฟล์ไม่ถูกแก้โดยไม่รู้ตัว
สถานะข้อมูล: **SOURCE** = มีแหล่งอ้างอิงภายนอก · **CANDIDATE** = จากเว็บ/บทความ รอตรวจ · **UNVERIFIED** = ความเชื่อ/ค่าที่ยังไม่มีใครยืนยัน · **SYNTHETIC** = สร้างขึ้นเพื่อสาธิต ไม่ใช่ข้อมูลจริง

> ความเชื่อทั้งหมดเป็น "claim จากแหล่งอ้างอิง" ไม่ใช่การรับรองความศักดิ์สิทธิ์ ข้อมูลสมมติทุกชุดติดป้าย `SYNTHETIC` / `DEMO_ONLY_NOT_OFFICIAL`

## 5. แหล่งภายนอกที่อ้างอิงในข้อมูล
ชีต `CL_RITUAL_CLAIMS`, `CL_OFFERING_SOURCES`, `GD_PLACES`, `CL_HOURS_CANDIDATES` มี URL ของเว็บภายนอก (ประมาณ 125 ลิงก์ในไฟล์ 01 และ 120 ในไฟล์ 02) เช่น เว็บมูลนิธิ พจนานุกรม และเว็บท่องเที่ยว
- repo เก็บเฉพาะ **ข้อความอ้างอิงสั้น ๆ (claim) พร้อมลิงก์ที่มา** ไม่เก็บบทความหรือเนื้อหาของเว็บเหล่านั้น
- **ยังไม่ได้ตรวจสิทธิ์/ToS ของแต่ละแหล่งอย่างเป็นทางการ** (ระบุไว้เป็นงานค้างในรายงาน) ผู้ที่นำไปใช้เชิงพาณิชย์ต้องตรวจก่อน
- ถ้าเจ้าของเว็บใดต้องการให้ถอนการอ้างอิง ให้ลบแถวนั้นจากชีตและ `ritual_claims.json` แล้วรันเทสต์

### 6.1 เวอร์ชันของคำถามคะแนนดาว (rating) ในฟอร์ม feedback
| เวอร์ชัน | ใช้ตั้งแต่ | คำถาม | ค่าใน sheet (คอลัมน์ `scope`) |
|---|---|---|---|
| `V1_GENERAL` | ก่อน 2026-11-23 | ให้คะแนน 1–5 ดาวต่อ Demo โดยทั่วไป | `DEMO_UX_FEEDBACK_NOT_REAL_SERVICE` (ไม่มีส่วนต่อท้าย) |
| `V2_RELEVANCE` | 2026-11-23 | "สถานที่/ทริป/บริการที่แนะนำนี้ตรงกับความสนใจของคุณมากน้อยแค่ไหน" (1 = ไม่ตรงเลย, 5 = ตรงมาก) | `DEMO_UX_FEEDBACK_NOT_REAL_SERVICE\|RATING_Q=V2_RELEVANCE` |

- โครงสร้างคอลัมน์ของ Sheet และ Apps Script **ไม่เปลี่ยน** เวอร์ชันถูกบันทึกในข้อความของคอลัมน์ `scope` ที่มีอยู่แล้ว
- แถวที่ไม่มีส่วนต่อท้าย `|RATING_Q=` ให้ถือเป็น V1 ห้ามนำคะแนน V1 และ V2 มาเฉลี่ยหรือวิเคราะห์รวมเป็นสเกลเดียวกัน
- ผู้ใช้ยังไม่ได้เดินทางไปขอพรจริง จึงเปลี่ยนจากถามความพึงพอใจเป็นความตรงกับความสนใจ

**คำถามความสนใจ (ฟิลด์ `would_use_again`)** — เพิ่มเมื่อ 2026-11-23 (รอบเดียวกับ V2)
| เวอร์ชัน | ความหมายของ `would_use_again` | ค่า | ตัวระบุใน `scope` |
|---|---|---|---|
| (ไม่มีตัวระบุ) | **ไม่มีคำตอบในฟิลด์นี้** (หน้าเว็บไม่เคยส่งค่านี้ก่อน V2 ฟิลด์ว่าง) | — | ไม่มี `\|INTEREST_Q=` |
| `V1_PREUSE_INTEREST` | "คุณสนใจ{สถานที่/ทริป/บริการ}ที่แนะนำนี้หรือไม่" ถามก่อนใช้จริง = **ความสนใจก่อนใช้** | `YES` สนใจ · `MAYBE` ยังไม่แน่ใจ · `NO` ไม่สนใจ | `...\|INTEREST_Q=V1_PREUSE_INTEREST` |

- ห้ามตีความฟิลด์นี้เป็น "จะกลับมาใช้ซ้ำ" (Repeat Usage) แม้ชื่อฟิลด์จะเป็น `would_use_again` ใช้ชื่อเดิมเพื่อไม่เปลี่ยน Sheet Schema และ Apps Script
- เซิร์ฟเวอร์ปฏิเสธคำตอบที่ส่งมาโดยไม่ระบุเวอร์ชันของคำถาม

**สถานะหลังกดส่ง (ที่ผู้ใช้เห็นและที่ API ตอบ `mode`)**
| `mode` | ความหมาย | บันทึกจริง | ปุ่มลองใหม่ |
|---|---|---|---|
| `saved` | Apps Script ตอบ `ok: true` | ใช่ | — |
| `not_configured` | ยังไม่ตั้งค่า `FEEDBACK_WEBHOOK_URL`/`FEEDBACK_TOKEN` (โหมดสาธิต) | ไม่ | ไม่มี |
| `bad_webhook_host` | URL ปลายทางไม่ใช่ `script.google.com` | ไม่ | ไม่มี |
| `rejected` | ปลายทางตอบไม่ใช่ `ok: true` | ไม่ | ไม่มี |
| `unreachable` | เชื่อมต่อปลายทางไม่ได้/หมดเวลา | ไม่ | มี (ปัญหาชั่วคราว) |
| (เรียก API ไม่สำเร็จ) | คำขอไม่ถึง API | ไม่ | ผู้ใช้ส่งใหม่ได้เอง |

หน้าเว็บแสดง "ขอบคุณ/บันทึกแล้ว" เฉพาะ `saved` เท่านั้น
